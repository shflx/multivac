# 设置 · 统计的数据契约

统计作为全新功能，只记录接入采集后的模型调用。使用独立的新调用账本，不读取 Pi 历史、不回补旧用量、不兼容旧统计账本。页面不展示启用日期、历史覆盖状态或历史兼容说明。

页面只提供近 7/30/90 天，默认 30 天；依次展示四项总览、每日柱图、模型/项目/来源分布和用量最多的五个会话。布局参考 prototypes@d52053a 的统计页，正式功能不使用原型示例数据，不提供费用、项目筛选、导出或预算入口。

## 真实调用与统计口径

每次 ModelRuntime 的 stream/streamSimple/complete/completeSimple 终态 AssistantMessage.usage 是采集来源，覆盖 Multivac 协调、工作会话和任务执行。一轮内多次模型调用全部计入；用户发送数、工具调用数和运行结果的最后一条 usage 不代替模型请求数量或累计。

每次调用生成请求 UUID，在 SQLite 中保存调用时的会话、模型、项目与来源快照，终态只补同一请求的用量。重复终态不增加计数；重启保留账本，不重发模型调用。采集不改写模型响应或 Pi 历史，也不受执行诊断开关影响。会话改名、归档或删除不删除账本，无法确认的新调用归属仍如实标记未知。

接受非负安全整数 input/output/cacheRead/cacheWrite/totalTokens，并要求四项分解之和等于 totalTokens；推理字段存在时必须不超过 output。非缓存输入为 input + cacheWrite，缓存命中为 cacheRead，输出为 output（已含推理），总量为三段之和。输入总览包含非缓存输入与缓存命中；缓存命中率为 cacheRead / 输入总览，分母为零显示“—”。缓存写入和推理不重复相加，不存储费用、正文或凭据。

Pi SDK 可能将上游未报告的缓存字段归一化为零，当前账本无法区分未报告缓存与真实零命中；字段合法性和总量分解校验不能证明缓存字段确实由上游返回。缓存数据按 SDK 上报值累计。

例如 input=100、cacheWrite=20、cacheRead=80、output=40、reasoning=10、totalTokens=240，三段为 120/80/40，总量 240，输入总览 200，命中率 40%。

有效用量按实际值累计，失败、取消有可信正数 usage 也计入。失败、取消且没有有效用量的调用不计缺失；所有 pending（包括进行中和服务重启遗留待返回）均不计缺失，不推测其终态。成功结束但缺失、异常或无法区分提供方真实零值与 SDK 默认占位的全零 usage 仍计缺失，并在模型请求指标下提示数量。上述调用全部保留请求数，不伪造 token；全零响应保留原始字段用于核对。新记录与已有独立调用账本在查询时使用同一规则，无需清理数据库。

## 时间范围与聚合

GET /api/usage?days=30&timeZone=Asia%2FShanghai。days 只接受 7/30/90，默认 30；IANA 时区由浏览器传入，默认 UTC，非法值及重复、未知参数返回 400，不接受项目筛选。

单次查询固定 generatedAt，按调用开始时间归入用户时区的日历日；当前周期包含今日及前 N−1 天，上期为紧邻的前 N 天，不以 N×24 小时推算夏令时日期。每日固定返回 N 项，没有账本记录的日期显示零。

日均分母为所选范围内实际启用采集的日历天数，启用当天和今天各按一个日历日计。启用时间仅在内部持久化用于计算，重启不重新起算，接口及页面不展示它。当前有缺失用量或采集异常时，日均为空，页面不显示占位文字。只有上一周期全部处于采集启用后、两期无缺失且上期总量大于零时才计算环比，否则环比为空，页面隐藏对比文字。服务未运行时没有本功能发起的调用，不将停机时段渲染为未知日期。

总览、每日、全部分布与会话 Top5 共用同一记录集和累加器。requests 是所有已观测调用数，measuredRequests 是有可信有效用量的调用数，missingRequests 只计成功结束但没有有效用量的调用；因此 requests >= measuredRequests + missingRequests，差额包含无有效用量且不计缺失的失败、取消和待返回调用。仅有这些调用时已记录用量显示 0，请求数保留；缓存命中率和份额等无分母指标仍为空。份额分母为已记录 token 总量。项目按稳定身份分组，明确无项目与无法确认归属分开；会话按 ID 累计，在有有效测量的会话中按 token 降序与稳定身份次序取前五，不提供跳转。

首次读取、读取失败与空账本区分：尚未拿到响应不展示零，失败可重试并保留已有快照；成功读取的空账本显示零。采集写入错误保持模型执行，并提示当前只能展示已记录用量。
