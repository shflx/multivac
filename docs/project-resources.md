# 项目资料

项目资料是围绕项目整理的一组文件，比如需求说明、设计稿、参考规范。它与项目目录中的工作成果分开呈现，入口在“设置 · 项目”详情的“资料”标签；“概览”保留目录、默认约束、MCP 与权限。

## 来源

- 新建文档：在资料目录中创建 Markdown 文件，未带扩展名时补 `.md`，创建后用系统默认程序打开。
- 从项目目录选择：登记项目目录中已有文件的引用，不复制。路径可以是绝对路径或相对主目录的路径，按真实路径核对位于项目的某个目录之内。
- 从本机添加文件：复制一份到资料目录，单个文件不超过 20 MB。

资料目录是工作文件根目录下的 `project-resources/<项目 id>/`，不写进用户的项目目录。重名时在扩展名前追加序号，从不覆盖已有文件。移除资料目录中的文件时，文件放进以“项目名 的资料 文件名”命名的目录后移到废纸篓；移除目录引用只去掉登记，文件保持不动。

列表读取时现查文件状态，文件被移走或删除时标记“文件缺失”。标题默认取文件名，可以改；简介默认取 Markdown 的第一段正文。

## 打开

“打开”交给系统默认程序（macOS `/usr/bin/open`），“在文件管理器中显示”在 Finder 中选中。两者与工作区文件定位使用同一套本机入口校验：本机身份、回环对端、同源 Origin 与 Fetch Metadata，远程请求一律拒绝。会直接运行或安装的类型（如 `.app`、`.command`、`.pkg`）不代为打开，只能定位后由用户处理。

## 智能体

任务执行会话与指定智能体的工作会话轮次在执行约定中带上项目资料：索引列出标题、资料 ID、路径与简介，常驻资料附全文。只有文本类资料可以常驻，常驻合计不超过 24,000 字。其他资料由智能体按需调用只读工具 `read_project_resource` 读取，单次最多 40,000 字，非文本资料只出现在索引中。资料内容作为数据提供，不是指令。

第一版不区分资料用途，统一作为背景参考。


引用文件在每次读取、常驻注入、打开及定位时，都会按项目当前目录与真实路径重新校验；目录卸载或文件被链接到范围外后，资料标记为不可用，不继续读取正文。生产和开发实例都拒绝资料目录通过链接逃出本实例工作根。

常驻文件在外部编辑后仍按 24,000 字的共同预算注入，超过部分明确提示截断。文本使用有界文件读取，不先把完整文件载入内存；截断不拆开 UTF-16 代理对。
