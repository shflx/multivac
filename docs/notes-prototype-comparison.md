# 独立笔记原型对照

参考对象是固定提交 `d52053a85bba2bc385e79bfb624978afda801436` 的 `prototypes/app.jsx`。本轮通过受控只读 Git 读取对象，核对 `NoteEditor`、`NoteAssistant`、`NotesApp`、`CompanionSession` 与 `StackPath`；未依赖其他工作树的当前文件。相关组件位于原型约 4360–4580 行。

下面是源代码与实现结构的对照，不是浏览器截图或像素符合证明。浏览器未能启动，视觉、交互和窄屏可用性仍待本地核验。

| 原型内容 | 本次范围与实现 | 核对结论 |
| --- | --- | --- |
| 左笔记库、中 Markdown 编辑器、右梳理助手 | `NotesApp`、`NoteEditor`、`NoteAssistant` 三栏，复用项目主题变量 | 已核对组件与样式结构；未视觉验证 |
| 笔记库新建、当前选中、标题及更新时间 | 接入独立持久 API、稳定 ID 和服务端更新时间 | 真实数据路径已实现，运行待核验 |
| 可编辑标题、Markdown 原文 textarea | 保留原文编辑，新增显式保存及版本显示 | 保留原型编辑方式；不额外增加预览入口 |
| 标题栏梳理助手开关，收起后主栏扩展 | 开关渲染到标题栏；助手收起宽度为零，保留讨论挂载和草稿 | 已对齐代码位置；待浏览器核对 |
| 编辑器上方的 textarea 选区操作 | 助手模块持有处理逻辑，通过 portal 在编辑器上方呈现引用及深入 | 保留真实 UTF-16 位置，不 trim 或合并用户空白 |
| 引用预览、移除引用、当前笔记专属输入框 | 单次引用带正文 revision；发送重新核对，版本变化要求重选 | 实现可核对的版本及讨论身份 |
| Enter 发送、Shift+Enter 换行 | 输入框处理非 IME Enter；Shift+Enter 保留换行 | 已对齐代码；自动用例待运行 |
| 栈式深入和返回上一层 | 持久父子讨论、固定主题、层级恢复选择；父子分别保留历史与模型 | 保留操作语义；使用返回按钮和讨论下拉替代原型纯文本路径 |
| 整理结构、润色、补关联 | 整理结构、润色、梳理关联，以及生成修改建议快捷提问 | 关联严格指本笔记已有内容，服务没有跨应用检索工具 |
| 理由、修改前后、接受/拒绝、失效提示 | 持久差异卡片、稳定消息来源、版本及唯一定位保护 | 生成/拒绝不改正文，接受才事务应用；待真实模型及运行核验 |
| 原型示例状态、回复与本机数组 | 替换为 SQLite、共享会话控制器与真实 Pi 链路 | 产品实现没有示例回复或内存数组替代持久化 |
| 交给 Multivac、安排工作提示、跨页面上报 | 按最终范围移除 | 笔记 UI 不保留这些按钮、交接文案或占位动作 |
| 纳入知识库、收进笔记、原型 knowledge/notebook 收集关系 | 按最终范围移除 | 无跨应用收集，阅读笔记不自动迁移 |

实现增加了原型未表示的数据保护：保存失败时保留原命令、多窗口版本对照、未保存草稿恢复、稳定 Pi 来源核对、建议重复接受幂等。接受一条建议会使同一旧正文版本的其他待处理建议失效，这是本次保守的版本策略；不尝试自动重定位。

桌面浏览器用例会产出 `notes-three-columns.png` 到 Playwright 输出目录，只有本地成功运行后才有实际截图。当前没有生成或提交产品截图。完整实现、接口、限制及本地验证命令见 [独立笔记设计说明](design/notes.md)。
