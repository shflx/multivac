# 父任务单会话执行任务树

## 行为

启动父任务时读取完整后代集合，保存到父任务的 TaskRun.treeTasks。无子任务仍使用现有单任务运行。有子任务时也只创建父任务的 Run、执行会话和工作目录，没有独立计划实体或子任务调度器。

Agent 使用 get_task_execution_tree 分页读取固定范围、当前状态、成果摘要与本轮候选；使用 report_task_child 登记进展或相对父任务执行目录的成果文件。中间父任务在下级候选之后整合，根任务最后调用 submit_task_result。

子任务通过 executionTaskId 标明执行来源，currentRunId、sessionId 引用父运行作为成果来源，不代表存在独立运行。任务详情的 runs 仍只列该任务自己的运行。运行总览排除共享来源 Run 的子项，防止重复计数。

## 子任务即时进度

Task.executionProgress 保存本次处理阶段，与正式 status 分离。绑定父运行后为 pending（待处理）；Agent 开始处理前调用 report_task_child 不带成果，写入 processing（处理中）；完成时先带 title/path 登记成果，立即写入 ready（已处理，待核对），再推进下一项。正式交付前 status 仍保持 waiting，不放行树外依赖。

父运行停止时，尚未登记成果的 processing 子项变为 paused（待继续）；恢复重新绑定时，有保留候选的子项仍为 ready，其余为 pending。正式审核、完成、失败和人工请求优先显示。取消释放子项时清除处理阶段，独立启动也清除原父执行进度。旧数据没有该字段时沿用旧标签。

## 候选与交付

同一运行内，已登记的子项候选可以作为内部后续步骤的推进依据；它不是持久化交付状态，不能满足树外任务的依赖。候选文件可能继续变化，因此只有父运行 settled 且 stopConfirmed 后才读取文件，保存 SHA-256 固定版本，并按依赖、下级任务顺序逐项完成自检或生成审核请求。

根任务的实际交付检查完整固定后代集合，不仅检查直属子项。候选缺失、文件失效、人工步骤未完成或依赖退回时不能交付整体。结构自检、工具失败、人工作业和验收继续使用原规则。review 与 done 均可满足交付依赖，不自动通过人工验收。

父任务还在审核中时，子项被退回会暂停父任务并使其旧审核请求失效，用户从父任务继续修改。已完成的父任务不自动回滚。

## 范围与控制

- 全树分页读取；校验显式依赖、祖先依赖及子项先于父项整合的组合循环。
- 同一项目和既有目录权限；不扩展目录或工具能力。
- 已被其他运行占用、未安全停止、初次启动时有失败/暂停/异常子项，或有未解决非审核请求时明确拒绝。
- 固定范围内子项不能单独控制、删除或修改执行边界；暂停继续由父任务控制。
- 运行中新增子项不进入当前范围。继续沿用快照并重新核对边界，不重新读取一份更大的任务树。
- 人工子任务保持人工完成流程，不生成子 Run。只等待人工子项或树外依赖时，Agent 登记已完成部分并正常结束本轮，以便固定前置成果；用户完成条件后继续父任务。真正需要澄清问题时才创建原人工请求，避免暂停中的候选与人工前置条件互相等待。
- 暂停不发布候选，恢复保留目录、会话及有效候选，但候选必须在新运行停止后重新读取核对。重做新目录时不复用旧文件候选。
- 取消父任务并确认停止后，未交付子项释放占用、保持暂停并保留来源记录，不批量取消子项。
- 共用原根任务预算；子项不单独计运行次数。自动推进不会补充预算。

## 已有成果与恢复

查询返回已有固定成果摘要、版本与是否位于当前执行目录。旧独立子任务目录中的代码不会自动合并或获得读取权限；需要材料时明确澄清，不能只看到完成状态就假定代码已在父目录中。

新字段可选，旧数据无需重写。旧单任务运行的继续仍走原路径；有快照的父运行恢复时保留该快照。应用启动仅对已确认停止且成功结束的运行补做未完成的成果固定，不重发模型执行。结果未知的活动运行仍走现有恢复/停止证明流程。

## 验证

服务测试覆盖多级任务、依赖顺序、105 个子项分页、循环拒绝、工具注入和调用、人工子项、暂停恢复、取消释放、审核退回、停止后成果固定及重启核对。浏览器测试覆盖父任务一次启动、子项无独立运行、重复启动拒绝和跳转父任务。
