# 运行事实与生命周期

运行页、顶栏和对话共享服务端快照。Task 是长期目标，Run 是一次执行，processId 是受控启动的独立进程身份；PID 不作为业务身份。普通工作会话不进入任务统计。

排队保持绿色并显示排队摘要，不能显示为正在执行。准备、执行和停止中计入活跃执行；停止未确认优先显示停止中或恢复核对，保留租约。授权、澄清和验收等待不算异常。主动暂停不算异常；预算暂停、失败、环境停止及恢复核对需要留意。没有过程证据时显示“尚无可验证的工具记录”，不用模型正文补造步骤。

已用时从 Run.startedAt（兼容旧记录时使用 createdAt）计算，未启动的排队记录没有用时；停止确认后使用持久化 elapsedMs，不再增长。它不是会话单轮用时。

| 事件 | 显式依赖进程 | 独立长期进程 |
| --- | --- | --- |
| 暂停、取消、完成任务 | 请求停止，核对退出 | 保留，显示任务已不在执行 |
| 本地服务正常退出 | 请求停止，核对退出 | 请求停止，核对退出 |
| 关闭浏览器标签页 | 保留 | 保留 |
| 服务崩溃后重启 | 只读核对，未知时保留资源 | 只读核对，未知时保留资源 |

任务状态不代表进程退出。停止仍被任务依赖的进程需要预览影响并在对应进程行内由用户确认，执行时重新核对版本。确认默认聚焦取消，Esc 只取消该确认并归还焦点；响应丢失时保留确认、原预览版本与命令 ID，重试由服务端幂等核对。发送信号、PID 消失、心跳超时都不能单独证明后代已收敛；无法证明时显示恢复核对，不重启、不释放冲突资源。

运行界面以 `prototypes` 分支 `bef98cd` 中 `prototypes/app.jsx` 的 `RunsView`、`RunIndicator` 及 `prototypes/style.css` 为呈现基准：统一管理页头，不额外显示说明段；两段紧凑四列列表、异常标记、深色日志尾部、进程行内影响确认；按管理页实际可用宽度换行。顶栏先显示运行指示，再显示 Inbox；浮层按异常、执行中分组，每项带状态徽标，同一异常不重复进入执行中分组，摘要只显示非零运行项。实际执行状态、排队解释、停止证明与分页仍读取服务端事实，不把原型示例当作真实执行记录。托管后端的实际平台与命令限制见执行隔离文档。

无进展观测阈值为五分钟，依据 Run 最后执行活动时间，没有活动记录时使用开始时间。仅对执行中且没有在途 Pi/原生工具的任务提示；长命令、人工等待、主动暂停、恢复核对均豁免。新活动解除该提示；不会自动停止、重新执行或释放租约。预算、环境和恢复异常沿用原执行服务的持久化原因及处理入口。
