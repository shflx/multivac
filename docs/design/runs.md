# 运行事实与生命周期

运行页、顶栏和对话共享服务端快照。Task 是长期目标，Run 是一次执行，processId 是托管执行的稳定身份；PID 与进程组 ID 是执行信息，不作为业务身份。普通工作会话不进入任务统计，其 bash 后台执行进入进程统计。

bash 统一登记会话、当前发送命令（executionId）、SDK 工具调用（toolCallId）、前后台模式、进程信息与运行状态。toolCallId 是不透明引用，允许 SDK 组合调用身份。默认 foreground，等待命令结果；持续服务选择 background，直接填写持续运行命令，返回 processId。timeout 在 foreground 限制运行时间，在 background 只限制登记后等待进程启动的时间；后台服务不会因启动等待参数到期而被结束，任务自身的执行时限和额度仍有效。启动等待不作为 HTTP 就绪证明。每次执行创建独立进程组，并以固定区域设置采样根、组和可靠识别的后代，信号前复核启动身份；采样间主动脱组且未被观察到的进程不保证回收。

前台执行完成后保留登记记录与日志，不持续占用运行页；前台启动器退出但组内后代仍存活时，保留活跃进程与停止入口。后台执行在一轮回复结束、切换会话、浏览器关闭或内部运行时重建后继续保留。工作会话使用独立的日志尾部轮转，输出增长不会触发旧任务托管入口的五分钟限制。进程创建不代表服务可访问，端口只在观测本次进程组的真实回环监听后公开。

停止当前执行仅清理所属 executionId 的进程；结束会话运行清理该会话全部轮次的登记进程，其他会话不受影响。运行页提供单进程停止与行内确认的会话整体停止，取消和 Esc 不执行。会话停止重试固定首次命令的清理范围，避免误停后来启动的服务。归档会话先清理其进程；清理未确认时保留会话与原目录。

应用正常退出统一请求托管进程退出，超时升级强制结束，核对组内非僵尸进程已退出后保存结果，再释放运行时与数据库。崩溃后只核对带身份的退出记录，未知时显示恢复核对，不按旧 PID 杀进程或自动重启。前台运行超时按失败记录并明确显示时限与已核对退出的原因。新任务 bash 与工作会话共用执行后端，可联网和派生开发进程；Run 额度与停止租约另行叠加，后台不绕过任务预算。旧运行保留原执行方式，未核对停止不转换。

运行页和顶栏浮层只显示活跃项：任务准备、执行、停止中，以及进程启动、运行、停止中。排队、暂停、等待、已结束和恢复核对不进入这两个列表。查询在分页前筛选，列表总数、摘要和空状态使用同一范围；当前页因执行结束失效时回到有效页。浮层展示进程名称、来源和端口，只有进程时也有可操作条目，头尾之间不保留空白分隔层。停止后的进程及时移出；响应丢失的原停止请求保留在结果核对区域，重试使用原命令身份与范围。

排队事实继续在待办及对话查询中保留，不能显示为正在执行。准备、执行和停止中计入活跃执行；停止未确认优先显示停止中或恢复核对，保留租约。授权、澄清和验收等待不算异常。主动暂停不算异常；预算暂停、失败、环境停止及恢复核对需要留意。没有过程证据时显示“尚无可验证的工具记录”，不用模型正文补造步骤。

顶栏及浮层的活跃进程数量、前五条明细和更多项提示，共用 `/api/processes?activeOnly=true&offset=0` 的同次响应；数量使用该响应分页前的 total。运行页翻页时另外补读首页，保留独立的首页快照。`/api/runs` 的任务统计和进程恢复核对统计保持原有口径，其独立采样的活跃进程数不用于浮层计数。短命进程在两次来源查询之间退出时，按已确认进程列表显示；不等待旧的运行摘要进程数归零。恢复核对单独提示，不混入活跃列表。

状态查询覆盖响应头及正文读取，10 秒未结束时终止前端读取并释放 loading；这不会取消服务端任务或进程。页面可见时每 5 秒核对一次，前台或网络恢复主动补读，并取消被替代的旧查询。首次读取任务或进程快照时分别显示读取提示，两路快照确认前不宣称当前空闲。后台核对期间保留已有明细，标明正在核对及上次确认结果。超时或读取失败期间保留已有列表，顶栏显示“状态待核对”（两路都没有已确认快照时为“状态不可用”），不再用旧空快照宣称当前空闲；重试成功前保留错误，成功后恢复正常标签。一路失败不隐藏另一路已有明细。迟到响应和旧版本不能覆盖新事实。

已用时从 Run.startedAt（兼容旧记录时使用 createdAt）计算，未启动的排队记录没有用时；停止确认后使用持久化 elapsedMs，不再增长。它不是会话单轮用时。

| 事件 | 显式依赖进程 | 独立长期进程 |
| --- | --- | --- |
| 暂停、取消、完成任务 | 请求停止，核对退出 | 保留，显示任务已不在执行 |
| 本地服务正常退出 | 请求停止，核对退出 | 请求停止，核对退出 |
| 关闭浏览器标签页 | 保留 | 保留 |
| 服务崩溃后重启 | 只读核对，未知时保留资源 | 只读核对，未知时保留资源 |

任务状态不代表进程退出。停止仍被任务依赖的进程需要预览影响并在对应进程行内由用户确认，执行时重新核对版本。确认默认聚焦取消，Esc 只取消该确认并归还焦点；响应丢失时保留确认、原预览版本与命令 ID，重试由服务端幂等核对。发送信号、PID 消失、心跳超时都不能单独证明后代已收敛；无法证明时保留恢复核对记录，由任务详情或对话查询核对，不重启、不释放冲突资源。

运行界面以 `prototypes` 分支 `bef98cd` 中 `prototypes/app.jsx` 的 `RunsView`、`RunIndicator` 及 `prototypes/style.css` 为呈现基准：统一管理页头，不额外显示说明段；两段紧凑四列列表、异常标记、深色日志尾部、进程行内影响确认；按管理页实际可用宽度换行。顶栏先显示运行指示，再显示 Inbox；浮层按活跃异常、执行中及进程分组，每项带状态徽标，同一异常不重复进入执行中分组，摘要只显示非零活跃项；空闲时头部只显示“空闲”，空状态说明只在正文出现一次。实际执行状态、停止证明与分页仍读取服务端事实，不把原型示例当作真实执行记录。托管后端的实际平台与命令限制见执行隔离文档。

无进展观测阈值为五分钟，依据 Run 最后执行活动时间，没有活动记录时使用开始时间。仅对执行中且没有在途 Pi/原生工具的任务提示；长命令、人工等待、主动暂停、恢复核对均豁免。新活动解除该提示；不会自动停止、重新执行或释放租约。预算、环境和恢复异常沿用原执行服务的持久化原因及处理入口。
