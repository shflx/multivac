# 任务卡片与详情呈现

本页记录任务概览和详情的信息层级，配合现有任务关系设计使用；不改变调度、停止、验收与权限规则。

- 卡片按标题、当前最重要的情况、关系进度及一个文字动作组织；未启动任务不展示静态前置条件，排队中的实际依赖等待保留在情况摘要中；取消数为零时省略，单项目筛选下不重复项目名。看板不展示父任务，列表仅在父任务未呈现且没有缩进上下文时保留父任务入口；子任务进度仍保留。拖动手柄在悬停或键盘聚焦时强调。
- 详情先展示任务身份、项目与优先级、当前情况和动作，再展示待处理请求。取消与删除收进更多操作；授权直接打开原任务会话，不生成新的决定入口。
- 长目标可展开；无成果时不常驻空区；待验收版本只在原请求中预览，其他成果展示最新版本，历史版本可展开。
- 子任务有真实进度时展示列表，无子任务仍保留创建入口。父任务入口靠近标题，关系区域只展示直接父任务，不展示祖先链或直接后续任务；已满足的前置任务按需展开。反向依赖查询及服务端删除保护保留。默认不展示内部 ID；编辑过程中的限制和冲突说明保留。
- 前置任务和直属子任务统一为整行可点击的“左侧标题、右侧真实状态”；标题最多两行，状态不换行并对齐标题首行，不再在标题下重复状态，也不另列“尚未完成／条件已满足”。前置条件的整体汇总保留。
- 最近进展先显示四条，可展开已读取记录及继续分页；范围、目录与执行信息默认折叠。加载与错误状态不伪装为空数据。
- 详情宽屏约 440px，空间不足时在面板内部覆盖展开；标题和关闭入口保持可达。菜单支持 Esc、外部点击和焦点返回，重要动作不依赖悬停发现。
