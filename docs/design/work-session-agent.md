# 工作会话本轮智能体调用

普通工作会话可以在输入区通过 @ 搜索并选择一个已有执行智能体。选择是正文之外的可移除标记，仅作用于一次独立发送及其运行中追加。标记显示服务端解析的模型与推理等级；消息必须包含正文或图片。候选排除固定协调者，允许通用执行。

## 身份与受理

发送只携带稳定 agentId。正文、邮件、代码、引用中的 @ 名称均为用户数据，不解析为调用。服务端复用智能体准入与模型目录，跟随默认时按全局默认解析，不使用当前会话模型替代。发送前预览与真正受理分别核对配置；失效配置拒绝发送。

受理账本保存智能体 ID、revision、当时名称、模型显示名、实际模型身份与推理等级，私有配置另外保存执行指令及必要模型设置。配置不包含模型秘密。公开回执、接受事件、历史锚点与轨迹只投影展示快照，客户端不能指定 executor 或模型配置。

agentId 进入命令指纹。同一 commandId 换智能体报冲突，重放已受理命令读取原回执，不重新取智能体现状或重新执行。没有智能体字段的旧命令保留原指纹。已受理后编辑、改名或删除智能体，不改写既有执行快照与历史。

## 同会话执行与收尾

复用现有 Pi session、上下文、工具与公共事件流。系统规则、项目默认约束及工作目录 AGENTS.md 与智能体指令并列适用，智能体选择不扩大目录、工具、授权或业务操作能力。

目标模型在既有配置与凭据版本边界内准备和复核。本轮只改既有 Agent 的内存模型、推理等级和系统提示；现有唯一受控扩展在 before_agent_start 时再次合并本轮指令，防止 SDK 请求前重建基础提示覆盖临时设置，收尾同时清空该指令来源。不调用永久选模 setter，不写会话选模账本，也不创建独立智能体会话。指定的等级若不受 Pi 支持，明确拒绝，不静默降级。

没有配置推理等级时，复用模型默认设置；模型也没有等级设置时，按其真实能力适配基础等级，预览与受理均显示解析结果。显式设置的等级失效时仍拒绝。

prompt settled 后，无论成功、失败或停止，都恢复原模型、推理等级、系统提示与认证运行时。激活部分失败也恢复。无法确认恢复时阻止该运行时继续发送；应用重启按永久会话选择恢复，不重发旧命令。回复及工具结果保留在同一历史中，这种调用不能作为独立上下文审查。

## 追加、草稿与恢复

steer 与 followUp 均追加到当前 prompt，沿用其执行快照。服务端拒绝指定不同智能体；认证等待结束后再次核对原 prompt 身份和 streaming 状态，不能把迟到追加改派到新运行。独立下一轮按自己的明确选择处理，未选择时使用原会话配置。

选择和正文、引用共用页面草稿版本，挂起命令另存完整发送快照。受理消息的标记只消费一次；用户已开始写下一条正文时保留新正文，同时移除已受理选择，防止旧标记带入下一轮。迟到回执不能清除另一个选择。

智能体命令的响应未知时只读核对原 commandId，保存原选择与输入，不按当前新草稿重发。明确失败后与默认执行者同样处理：未送达时正文、引用连同智能体选择回到输入区，已受理后的失败作为会话事实保留；再次发送创建新命令，并重新校验该智能体当前是否可用，不回退到默认执行者。附件和引用保持原快照，失效资源明确报错。

回复作者、当前执行者、工具与错误轨迹按命令和 Pi 消息身份关联，不按正文或时间猜测。历史展示使用服务端快照，不查后来改名或删除后的配置。

## 开放范围

全局 Multivac、阅读书伴、笔记助手及任务执行会话不开放此入口，服务端也不注入本轮智能体解析能力。该能力不引入多智能体并发、自动委派、独立记忆或 CLI/PTY 后端。工作区继续遵循现有桌面视口边界，不借此功能开放移动端工作区。
