# Inbox 契约与验收矩阵

## 身份与事实

统一 ID：人工请求使用原 requestId；目录授权使用 `authorization:<原授权 ID>`，任务中的授权镜像与普通会话授权只计一次。来源保留 taskId、sessionId、固定 artifactVersionId；没有任务的会话不虚构任务。
排序：阻塞工作优先、创建时间升序、ID 升序。服务端过滤后分页，计数读取完整集合，不以历史上限或当前页代替总数。

pending 表示当前可决定；answered 保存决定回执；invalidated/expired 表示原决定入口失效。过期授权不再计待处理，需回原会话重新发起真实工具调用，旧请求不可复活。unknown 表示外部操作已获准但结果尚待只读核对，不能再执行。

## 五类处理边界

| 类别 | 事实及动作 | 必须验证 |
| --- | --- | --- |
| 澄清 | 原 HumanRequest；回答、不采用、保持停止；范围说明仅影响任务反馈，不授予目录权限 | 空答复拒绝；暂停不自动解除；取消后迟到答复拒绝 |
| 目录授权 | 原 ToolAuthorization；单次、会话、项目、拒绝；可记住范围由服务端计算 | 普通/任务/全局会话完整汇总；过期与重启失效；Agent 无批准入口 |
| 外发 | 本轮适配 Git 分支发布：固定仓库、远端、commit 和目标 ref；用户界面批准一次 | 预览固定提交；只创建原先不存在的远端分支；只读 ls-remote 核对，未知不重推；拒绝不执行；不因此完成任务 |
| 验收 | 原 HumanRequest + 固定成果版本，接受/修改 | 新版替换旧请求；验收不授予发布；其他 pending 阻止完成 |
| 恢复 | 原 HumanRequest + 原 Run，继续/停止/安全重做 | 停止证明与工具副作用标记完整；新 Run 不重放旧命令；用户暂停和预算/依赖不被绕过 |

安全重做定义为：旧执行停止且没有未核对工具调用后，保留原工作目录变更，从新会话启动新的 Run，先核对现有文件；不回滚目录、不重放外部操作、不清除预算。无法证明停止时禁用继续和重做。

## 入口与交互

顶栏抽屉、管理完整页、任务卡、就地会话卡与 Multivac 查询使用同一身份。处理后保留当前回执，仅用户点击下一项才切换；新请求不抢焦点。管理页保留桌面边界，窄屏使用抽屉。来源只跳转真实会话或固定版本；失效来源明确报错。

查看与草稿独立于业务 revision，在 SQLite 持久化，所有本地窗口共享；草稿使用 revision 冲突控制，后台读取不能覆盖尚未保存的本地编辑。刷新恢复草稿；保存失败保留输入并提供重试。选择和滚动只属于本窗口，不广播。授权范围默认单次，不将旧选项自动用于新请求。

决定绑定命令 ID、请求 ID、revision 与输入。重复点击共用在途操作；失败保留输入，响应丢失先对账；同 ID 不同参数冲突。查看写入仅发生于实际可见详情，预选、隐藏管理页不触发。

## 验收

服务端：跨来源去重、超 100 条计数、分页稳定、并发决定、重启/取消/过期、旧版本与外部结果未知。
共享状态：旧事件不复活终态、断线重读、多窗口草稿冲突、刷新恢复、处理失败保留输入。
界面：五类请求、空/加载/失败态、长内容、原位回执、主动下一项、Esc/焦点循环/归还、窄屏、抽屉转管理及来源返回。
