# 工作区文件操作

文件树、搜索结果和当前文件标题使用相同的右键菜单与可见更多按钮。菜单操作绑定该入口的会话、原工作目录、路径与目标类型，不使用另一个选中项或并排栏焦点。Shift+F10 打开菜单，方向键移动，Esc 关闭并返回更多按钮。最近查看与根目录也提供对应菜单。

复制绝对路径和名称时，服务端重新核对原根目录、可浏览范围、符号链接及目标类型，返回真实路径和名称。前端原样写入剪贴板，只有写入成功后才提示成功。文件名含扩展名，目录复制目录名。目标失效、目录变更或剪贴板拒绝均反馈错误。

“引用到当前会话”只用于文件。它替换所属工作会话的单个引用草稿，保留正文和图片，不自动读取全文或发送。来源引用使用 `sourceKind: file`、`quoteKind: source`、空 `text` 和固定 `sourceFile.root/path`；它不能携带行号、章节或伪造正文。旧文件选区缺省仍为选区，必须有非空文本，保持原快照和大小限制。

来源引用不依赖文本预览，因此二进制及超过预览上限的普通文件也可引用。发送前重新校验文件类型、原根目录和路径；跨会话的文件来源发送被拒绝。模型收到明确来源位置和原权限说明，读取仍受原工具及目录边界限制。来源失效时保留草稿。来源类型和身份随原命令进入幂等指纹，未知结果沿用原命令及快照，已发送历史保存原来源。

针对性验证包括目标服务、来源契约、Pi 历史、发送幂等及草稿控制器；浏览器用例位于 `tests/e2e/file-actions.spec.ts` 和 `tests/e2e/file-source-quote.spec.ts`。运行结果与本机实测限制由交付成果记录。
