# 通知渠道

通知副本只适用于 Inbox 的提醒通知。澄清、目录授权、外发授权、成果验收、恢复确认和 MCP 调用授权均不在外发来源内。外部发送、阅读和回复不会处理 Inbox 事项；请回到 Multivac 操作。

## 期限与投递事实

用户已确认外部投递有效期为 Inbox 通知生成后24小时。过期停止开始外发及重试，原通知保留。原计划时间与通知生成时间分别保存。服务停机后恢复发送不表示准时发送。此期限是本地队列策略，不是微信上下文寿命或服务端可发保证。

首次启用不补历史，暂停期间生成的通知重新启用后也不补发。停用、知道了和绑定变化取消未开始的投递；在途请求可能已被服务端处理，不能保证撤回。接口接受不等于手机实收。未知结果默认不重发，没有一键盲目重发入口。微信首版不声明已验证的远端幂等或送达查询能力。

## 微信协议与私有资料

参考项目 [Tencent/openclaw-weixin](https://github.com/Tencent/openclaw-weixin/tree/874637a0dbc24050f72d1385add4fc6170a2d726)，固定提交 `874637a0dbc24050f72d1385add4fc6170a2d726`，包 `@tencent-weixin/openclaw-weixin` 版本 `2.4.10`，MIT许可。仅改编无损 uint64 JSON 标识解析器，许可全文见 [版权与许可](third-party/openclaw-weixin-LICENSE.txt)。其他代码为独立实现，没有引入整个插件。

已核对参考源码的 `get_bot_qrcode`（bot_type=3）、`get_qrcode_status`（含验证码和IDC跳转）、`getupdates`、`sendmessage`、`msg/notifystart` 和 `msg/notifystop`。参考元数据为 `iLink-App-Id: bot`、客户端版本 `0x02040a`、`channel_version: 2.4.10`。本实现另声明 `bot_agent: Multivac/0.1.0`，不声明自己是 OpenClaw。这些兼容参数及开源许可不证明自建客户端已获微信服务端准入；真实账号登录、API调用与手机结果必须另行核对。

仅向已核验的微信 iLink HTTPS主机发送凭据；拒绝HTTP、额外端口、用户信息、外域及HTTP隐式重定向。二维码最多初次获取加两次刷新；验证码只在当前本机登录流程内保存。完整匹配 Bot、扫码本人、业务地址、渠道与绑定代次才恢复私有资料；仅返回“已经绑定”而缺完整身份不视为成功。

私有资料在实例数据目录的独立 `notification-secrets/wechat/binding.json` 内，以0700目录、0600文件保存。去重标识、本人非空context_token、观察时间与get_updates_buf通过整份文件的同步写入和原子替换一起保存。业务库只保存独立身份核对记录和投递事实，不保存token/context_token。入站不保存正文，不交给模型，也不能调用业务决定接口。非本人、非本Bot、群聊和非用户消息不能更新本人上下文。空上下文不覆盖；重复消息不推进上下文；轮询不延长上下文观察时间。

## 当前验证边界

自动化协议夹具可以证明本地字段、状态和保存行为；不能证明微信真实准入或手机收到。正式启用必须由用户主动发送唯一编号测试，并在 Multivac 明确确认手机实收。真实即时、10分钟、重启及隔夜结果需分别记录，不能由一次成功推断永久可用。
