# 会话上下文统计与压缩状态

普通工作会话和本机全局 Multivac 在输入区提供“上下文”入口，以圆环和比例显示占用。展开后可查看当前占用、模型窗口、统计模型、更新时间及不可用或过期原因，并可手动刷新。最近请求输入和计数覆盖说明仍随接口快照返回。后台任务、书伴、笔记助手及远程入口不增加主动压缩操作。

**已接入上下文查询和原生主动压缩。** 会话运行时已打开、空闲，且当前持久模型及会话身份可核对时，可以在输入框执行内置命令 `/compact` 压缩较早上下文。使用 Pi 的原生摘要链路及当前持久模型，不改变输入区本轮智能体的选择。模型、运行状态、持久记录或恢复证据无法核对时，命令在 / 菜单中保持可见但不可执行，并显示原因。

## 数值含义

- **当前估算**通常来自 Pi 的原生 `getContextUsage()`：最近有效助手用量（包含输出）加后续消息的启发式估算。只有存在有效用量、模型匹配且未经过后续选模／压缩边界时才公开该估算。压缩后、首次有效回复前，改用系统提示、启用工具定义和 Agent 消息的字符启发式粗估；提示与工具定义按字符数 / 4，消息沿用 Pi 的估算方法。新的有效回复到达后恢复用量加后续消息估算。两种来源均不是精确的下一次请求计数。
- **最近请求实际输入**来自历史助手消息的 `input + cacheRead + cacheWrite`，不含输出。缓存命中仍占上下文窗口，不能从中扣减。该数值属于原请求，不能标成当前占用。
- **不可用**保持 `tokens: null`。新会话、缺失或全零用量、压缩后无法取得有效粗估、最近用量属于其他模型或模型配置已经变化时，不显示 0 或百分比。

历史 transcript 不包含请求当时完整的 profile 来源和窗口上限，所以最近请求的 `model.source`、`model.profileId` 和 `contextWindow` 可以为 null；保留消息实际记录的 provider、modelId 和协议，不用当前选择或模型目录补猜历史身份。当前估算使用实际运行模型的已知窗口，只在 token 和窗口均已知时显示占用比例。

系统提示、工具定义、动态资料和附件在提供方统计中的完整覆盖尚未独立核验。新增工具结果按字符启发式估算，图片采用固定估算，均不应解释为真实视觉或完整请求 token。覆盖说明随快照一并返回。

运行中的估算标记过期；消息／工具、压缩、选模和运行生命周期变化后使旧读取失效并重新查询。返回前台、重新打开和事件流重连也重新查询。窗口内部同一会话共享控制器，迟到响应不能覆盖新会话状态或新模型状态。查询不会初始化 Pi 会话、写入操作记录或发起模型请求。

## 操作身份与门禁

应用层提供压缩意图账本和互斥边界。只有宿主支持、原生能力明确可用、会话空闲、revision 匹配、实际持久模型及会话绑定可核对时，才允许执行器取得资格。Pi 适配器声明原生能力，具体会话仍需逐次通过上述准入检查。

操作固定 ID、会话、模型和前后独立快照。意图先保存到 SQLite，同一 ID 的相同参数返回原记录，不同参数报冲突；同会话活动操作受数据库唯一约束和发送／选模共享锁限制。执行或待核对期间拒绝发送、选模和生命周期迁移。

通过 `/compact` 发起压缩后，输入区分别呈现成功、失败、取消、无内容、不可用和待核对，结束后可关闭反馈。上下文弹层只保留仍在执行或待核对的操作状态。压缩结束不是所属运行结束；原有自动压缩被取消时显示取消，不再显示完成。接口保留前后独立快照及各自来源，不计算跨口径压缩比例。

刷新、断线或服务恢复后只查询原操作，不重发 POST。执行前先保存 SQLite 意图，再在 Pi 内部会话目录独占创建并同步原文件长度、前缀摘要、叶节点和操作身份的证据。证据不包含原始聊天内容或凭据。只有证据可靠保存后才允许发起原生压缩。

执行结束后同步并严格解析 transcript，再从已核对的磁盘内容恢复 SessionManager 和 Agent 消息。SDK 抛错可能发生在内存已追加压缩之后，甚至磁盘已提交之后，因此不按异常直接判定回滚：原前缀完整、首条新增原生压缩记录与原叶节点匹配时判为已提交；没有新增提交时恢复原消息，并记录失败、取消或无内容的持久回执。历史仍走既有读取链路，压缩后可以继续对话。前缀被改写、追加截断、文件不可读或恢复失败时保持待核对并隔离当前运行时，禁止冲突执行。

只读核对不初始化 Pi、不补写摘要、不修复 transcript，也不更新业务账本。获得可靠证据后可展示原结果并解除逻辑占用；下一次发送、选模、压缩或生命周期迁移先保存核对结果，再改变上下文。正在执行或已隔离的运行时不能因查询而解禁。文件修复后仍受隔离的会话，需要重启服务后核对，不能把断线、请求超时、抛错或停止等待当成已回滚／已停止证明。没有新增原生取消按钮。自动压缩及其配置保持原有行为。

## HTTP 与应用边界

两种本机宿主复用同一会话接口：

| 操作 | 全局路径 | 工作会话路径 |
| --- | --- | --- |
| 查询快照及最近操作 | `GET /api/assistant/context` | `GET /api/sessions/:id/context` |
| 查询原操作 | `GET /api/assistant/context/operations/:operationId` | `GET /api/sessions/:id/context/operations/:operationId` |
| 提交压缩意图 | `POST /api/assistant/context/compact` | `POST /api/sessions/:id/context/compact` |

提交正文仅包含 `operationId`、`sessionId`、`revision`。请求和响应由共享契约校验。宿主、归档及会话身份沿用服务端会话解析，不从正文决定权限；排除宿主不开放这些路径。操作的内部绑定和文件引用不进入公共响应，错误只返回稳定说明。

Pi 专用类型只存在于运行时适配层；应用服务依赖 `CoordinatorContextManagementPort`，公开 DTO 仅含白名单统计与状态字段。原生执行和提交核对通过执行器端口提供。真实 Pi 0.85.1、真实文件系统和 SQLite 联合用例覆盖两种会话身份、持久结果丢失、关闭重开、写盘拒绝、已提交后抛错、截断追加、取消、历史保留和继续对话。测试模型传输为受控内存 SSE，浏览器压缩交互使用受控 HTTP 状态；这些结果不代表真实模型提供方的请求和计数覆盖验收。实际提供方及双宿主真实模型联合验收仍需合法测试模型配置。
