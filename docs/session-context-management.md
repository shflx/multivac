# 会话上下文统计与压缩状态

普通工作会话和本机全局 Multivac 在输入区提供“上下文”入口。展开后可查看当前估算、最近请求输入、模型及窗口、统计时间、过期状态和计数覆盖说明。后台任务、书伴、笔记助手及远程入口不增加主动压缩操作。

**当前可以查询上下文；主动压缩保持不可用。** Pi 原生压缩在持久写入失败时可能已经改变内存分支，不能保证应用继续使用的内存与磁盘一致。适配器仍声明 `nativeCompaction: false`，服务端拒绝执行，界面禁用按钮并说明原因。没有通过配置或发送总结消息绕过此门禁的入口。

## 数值含义

- **当前估算**来自 Pi 的原生 `getContextUsage()`：最近有效助手用量（包含输出）加后续消息的启发式估算。它不是精确的下一次请求计数。只有存在有效用量、模型匹配且未经过后续选模／压缩边界时才公开该估算。
- **最近请求实际输入**来自历史助手消息的 `input + cacheRead + cacheWrite`，不含输出。缓存命中仍占上下文窗口，不能从中扣减。该数值属于原请求，不能标成当前占用。
- **不可用**保持 `tokens: null`。新会话、缺失或全零用量、刚压缩后尚无有效回复、最近用量属于其他模型或模型配置已经变化时，不显示 0 或百分比。

历史 transcript 不包含请求当时完整的 profile 来源和窗口上限，所以最近请求的 `model.source`、`model.profileId` 和 `contextWindow` 可以为 null；保留消息实际记录的 provider、modelId 和协议，不用当前选择或模型目录补猜历史身份。当前估算使用实际运行模型的已知窗口，只在 token 和窗口均已知时显示带“估算”标记的比例。

系统提示、工具定义、动态资料和附件在提供方统计中的完整覆盖尚未独立核验。新增工具结果按字符启发式估算，图片采用固定估算，均不应解释为真实视觉或完整请求 token。覆盖说明随快照一并返回。

运行中的估算标记过期；消息／工具、压缩、选模和运行生命周期变化后使旧读取失效并重新查询。返回前台、重新打开和事件流重连也重新查询。窗口内部同一会话共享控制器，迟到响应不能覆盖新会话状态或新模型状态。查询不会初始化 Pi 会话、写入操作记录或发起模型请求。

## 操作身份与门禁

应用层提供压缩意图账本和互斥边界。只有宿主支持、原生能力明确可用、会话空闲、revision 匹配、实际持久模型及会话绑定可核对时，才允许执行器取得资格。当前 Pi 适配器没有开放此资格。

操作固定 ID、会话、模型和前后独立快照。意图先保存到 SQLite，同一 ID 的相同参数返回原记录，不同参数报冲突；同会话活动操作受数据库唯一约束和发送／选模共享锁限制。执行或待核对期间拒绝发送、选模和生命周期迁移。

界面分别呈现成功、失败、取消、无内容、不可用和待核对。压缩结束不是所属运行结束；原有自动压缩被取消时显示取消，不再显示完成。前后统计保持各自来源，不计算跨口径压缩比例。

刷新、断线或服务恢复后只查询原操作，不重发 POST。没有原生持久提交证据时保留“待核对”及占用，不把请求超时、抛错或停止等待当成已回滚／已停止证明。当前没有可以自动解除此状态的恢复操作，也没有原生取消按钮。自动压缩及其配置保持原有行为，聊天历史继续使用既有读取链路。

## HTTP 与应用边界

两种本机宿主复用同一会话接口：

| 操作 | 全局路径 | 工作会话路径 |
| --- | --- | --- |
| 查询快照及最近操作 | `GET /api/assistant/context` | `GET /api/sessions/:id/context` |
| 查询原操作 | `GET /api/assistant/context/operations/:operationId` | `GET /api/sessions/:id/context/operations/:operationId` |
| 提交压缩意图 | `POST /api/assistant/context/compact` | `POST /api/sessions/:id/context/compact` |

提交正文仅包含 `operationId`、`sessionId`、`revision`。请求和响应由共享契约校验。宿主、归档及会话身份沿用服务端会话解析，不从正文决定权限；排除宿主不开放这些路径。操作的内部绑定和文件引用不进入公共响应，错误只返回稳定说明。

Pi 专用类型只存在于运行时适配层；应用服务依赖 `CoordinatorContextManagementPort`，公开 DTO 仅含白名单统计与状态字段。原生执行和提交核对端口当前明确拒绝／保留待核对；应用账本与受控端口测试不代表真实 Pi 主动压缩已经可用。
