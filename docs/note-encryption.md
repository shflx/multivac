# 单篇笔记加密

“应用 · 笔记”的独立笔记默认保持普通存储。点击笔记工具栏的“加密此笔记”，输入共用密码；首次使用时会设置这个密码。设置密码不会加密其他笔记。阅读笔记不使用此功能。

加密保护标题、正文、全部历史版本、笔记图片及其元数据、摘要、命令回执、修改建议，以及笔记所属讨论中的标题、选区、消息、图片和相关快照。列表显示“加密笔记”，不提供私密标题搜索。

## 查看与编辑

每个窗口、每篇笔记分别解锁。共用密码相同，不表示一次解锁所有笔记。解锁后的保存仍写入密文。

连续 15 分钟无用户操作后自动锁定；刷新、关闭窗口、浏览器返回旧页面或服务重启后，需要重新解锁。后台读取和事件订阅不会续期。页面重新激活时先核对访问资格；资格失效时停止展示内容。关闭页面会清除内存凭证，并尝试通知服务端撤销；通知未送达时，服务端按有效期回收残留资格。

“锁定”结束当前窗口的访问。页面会先核对正文保存与密文草稿，再清除编辑器、历史、讨论和图片 Blob。相关进行中的讨论会停止，但无法撤回模型已经收到的内容。

只有明确确认“取消加密”，才把这篇笔记及其所属记录恢复为普通存储。

## 草稿与转换恢复

普通笔记沿用原来的草稿保护。加密笔记的浏览器持久区只保存密文草稿包，密码与解锁凭证不进入 localStorage 或 sessionStorage。草稿包由服务端用逐篇密钥保护，不把密钥交给浏览器；修改密码后仍能恢复原草稿。

工具栏底部显示密文草稿是否保存。网络或浏览器存储失败时，请保持窗口打开并使用“重试加密草稿”。在密文尚未写入持久区前，刷新或关闭会提示仍有未完成保存；强制结束浏览器不能保证保存尚未落地的输入。

加密前先保存当前正文，并检查本浏览器其他窗口的未保存正文。其他窗口有未保存或结果未知的正文时，先在对应窗口核对。窗口之间使用浏览器页面锁和消息通道协调；未应答的窗口会阻止转换完成，后台暂停的窗口不会因心跳变旧而被跳过。

转换中的旧控制器停止明文写回，现有草稿和讨论现场先形成密文包，再清理原浏览器记录。复制标签页和刷新会创建独立的新包，保留旧密文作为恢复来源。取消加密时，各窗口只恢复其当前指针所指的草稿，旧包不会重新成为活动草稿。

如果转换中断，页面显示待恢复状态。重新输入密码后核对并继续恢复；部分转换不会显示为完成。若加密已提交但响应丢失，只读核对状态后恢复浏览器草稿保护，不重发一次新的加密操作。

## 密码与助手

在笔记库标题旁的钥匙按钮中修改共用密码。修改时验证原密码，重新保护主密钥，并撤销所有旧访问资格。忘记密码无法恢复旧密文，没有清空密码后读取旧内容的入口。

全局助手和通用笔记工具不能读取、修改或解锁加密笔记，也不会继承页面的解锁资格。用户在解锁后主动使用本篇笔记的梳理助手，会把正文和引用交给当前所选模型；界面会说明这一点。讨论结果继续按加密方式保存。

## 保护边界

这是应用管理的持久内容加密。服务端和浏览器在解锁期间仍需处理明文，不属于端到端加密。当前数据与日志、应用管理的讨论文件使用可恢复转换，不假定 SQLite 和文件系统共享事务。

不承诺撤回已导出或已发送给模型的内容，不查找其他普通会话里已经复制的内容，也不保证历史备份、文件系统快照和磁盘残留被物理擦除。历史备份应自行妥善保管。
