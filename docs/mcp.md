# MCP 接入契约

本文随实现更新。数据契约、持久化、协议、账号、真实 Inbox 许可、公共执行器及本地能力管理页面已装配。对话管理提议和资源内容读取/引用仍待接入。登记、连接、分类、单次许可与实际执行分别核对，不互相替代。

## 身份和状态

- 服务的 `serviceId` 稳定。`revision` 用于管理并发，`configVersion` 是不含凭据的传输配置版本。启停与连接、可发现能力及调用授权分别保存。
- 账号通过稳定 `accountId` 绑定一个服务。公开记录只包含不透明 `credentialRef`、认证类型和状态；私有存储负责凭据值，不能把值或其摘要写入业务记录。
- 工具身份由服务身份与原始工具名派生。完整工具定义（说明、Schema、注解）计算 `definitionVersion`。目录快照绑定服务配置与账号版本；工具、资源或模板变化产生新目录版本，不修改旧快照。
- 服务声明注解是资料。用户效果分类是独立事实，绑定配置、账号、目录及工具定义版本，并引用真实决定。存储接口不是确认入口，不能用模型文字创建用户决定。
- 项目规则包含排除与账号引用，智能体规则包含偏好及效果上限，会话规则包含临时停用。每个服务与作用域只允许一条规则。运行身份固定适用规则的 revision，执行时仍需重新核对。
- 调用固定宿主、会话、命令、工具调用、任务、运行及执行者身份。`sessionId + toolCallId` 唯一，不能换 `callId` 重放同一次执行。

## 持久化端口

`McpRepository` 提供有界读取、配置历史和稳定命令对账。变更只能通过 `commit` 提供的 `McpTransaction.put` 写入；expectedRevision=0 表示新建，其后必须恰好加一。事实、无秘密回执及变更事件在同一短事务内提交，失败一起回滚。异步回调不被接受；事务内禁止文件、网络、进程和模型调用。

MCP 使用独立的、按 JSON 键排序的 SHA-256 指纹规则，不改变其他模块的历史账本编码。同命令同参数返回原回执，同命令不同参数报冲突。回执只记录对象身份及 revision，不保存凭据或远程原始输出。

迁移追加到现有迁移序列，沿用既有数据库升级前备份。目录、导入预览及资源快照不可修改；服务配置历史保留。账号版本变化不改写历史调用，也不阻止记录旧连接的真实关闭事实。

## 状态迁移

调用状态允许 `prepared → running → succeeded/failed/unknown`。取消先记录 `cancel-requested`；只有停止证据才能记录 `cancelled`。未知结果只能由核对转成已知终态，不能重置为 running 自动重放。真实业务执行器仍须负责停止证明和核对依据，单凭存储状态迁移不构成证明。

授权请求的 pending 可以终结为 allowed、denied、expired、cancelled 或 invalidated，已终结决定不可改写。许可、执行和执行结果分别记录。连接每次创建新的连接身份，断线后重新连接不得复用旧身份伪装同一连接。

## 协议与兼容范围

公共客户端实现 JSON-RPC 初始化、能力协商、tools/resources/templates 分页目录及变更失效，协议版本限定为 2025-06-18、2025-03-26，以及仅用于 stdio 的 2024-11-05。无已安装 MCP SDK（lockfile 仅有 Pi 的可选 peer 声明），本实现未新增依赖；本轮未联网获取协议资料，不宣称通过官方 SDK 一致性测试。

stdio 使用 UTF-8 按行消息，通过宿主核对后的 `McpStdioChannel` 传输；客户端不能直接 spawn。Streamable HTTP 支持 POST 的 application/json 与 text/event-stream 响应、会话头、协议头及 DELETE 关闭；不重定向、不重试。独立 GET 事件流和事件游标恢复尚不支持，因此调用前须显式 refresh 目录，不能依赖空闲时收到变更通知。旧 HTTP+SSE 不支持，在创建传输前明确报错，不自动回退。

服务端采样、elicitation、roots 请求及 prompts 自动执行均不启用；除 ping 外的服务端请求返回方法未启用。限制单次请求/响应及整个目录为 2 MB，最多 1000 项、100 个分页游标，重复游标拒绝。默认 RPC 超时 15 秒，取消只发送通知并停止本地等待，不能宣称远端副作用已停止。

`McpConnections` 按服务、账号和会话保存真实连接事实，异步阶段后核对配置/账号版本；目录变更立即使缓存不可用，refresh 成功后保留新快照。重连显式创建新连接。关闭失败保留活跃记录，不提供停止证明。生产宿主的进程/网络策略和私有凭据通过 `McpWireFactory` 装配；该端口必须只构造传输，实际启动由 wire.start 完成，不允许在工厂返回前启动未受跟踪的进程。

传输配置只存公开启动参数、cwd、环境变量名或远程地址。远程 URL 不接受内嵌用户名、密码、查询参数或片段，认证由账号端口提供。配置校验本身不授权目录、网络或进程；必须在启动与调用时分别经过宿主策略。用户不得把凭据写入公开参数，导入入口还需执行秘密字段检查。

## 有效能力规则

`McpRules` 是展示、候选和执行入口的公共解析器。服务启停 → 项目排除及明确账号 → 智能体效果集合 → 会话停用 → 宿主效果与传输权限共同限制能力；任一拒绝都保留原因。偏好只影响排序，不改变可用性。项目账号字段为 null 表示未选择，不静默回落到连接的其他账号；已撤销账号不可重新选入。规则写入核对 revision、服务/账号及宿主对象归属。

会话“临时停用”保存在本会话规则中，跨刷新、重启、归档恢复仍保持，直到用户显式重新启用；新会话不继承。切换项目或智能体不清除本会话停用，不覆盖新项目排除。运行身份固定项目/智能体/任务/Run 及全部适用规则版本；任何变化都需要重新核对，不静默换身份。

原型对照：已读取 prototypes@d52053a 的 ui-state.js 中效果等级、resolveAvailability、resolveCapabilities 和 app.jsx 的 SessionInfo。原型按线性 read/local/external/egress 等级比较，并用常用服务组织任务候选；实现使用独立效果集合逐项取交集，避免允许传输隐含允许写入。智能体偏好只排序，登记、偏好及会话重新启用都不能扩大宿主权限。项目排除、账号和会话临时停用均在服务端生效，不采用模型候选作为权限事实。

## 公共执行器接入

`McpExecutionService` 接入 `CoordinatorInternalTools`；Pi 的现有 customTools 桥与 Fake 的脚本工具入口共用 `list_mcp_tools` / `call_mcp_tool` 两个声明，不新建 harness。发现返回本轮实际参数 Schema、稳定工具身份和能力引用，调用包装的 arguments 再按该 Schema 验证。服务同名工具以 serviceId + toolId 区分，不覆盖内置工具。模型不取得凭据、分类确认或许可决定方法。

发送前从已发现目录固定配置、账号、目录/定义版本、规则、实际目录、项目、执行者与 Run；未分类或超出宿主边界的工具不进入候选。已有会话连接提供明确账号，项目账号存在时只能使用项目明确选择。任务可以根据明确项目账号及已发现目录建立独立本地连接；连接后目录版本不同则失效，不偷偷接受新定义。调用在原 toolCallId 内等待真实 Inbox 决定，原始参数、许可和调用对应同一身份。凭据等异步准备完成后，在实际 HTTP/stdio 发送前同步复核许可、规则、身份及取消状态，登记租约和 running 意图，再发送；该门禁拒绝时仍记为未开始。并发同身份共享执行；恢复、重连和重放不重发已知或未知调用。

stdio 的生产工厂复用 NativeTaskTools 的 macOS 沙箱：只接受绝对可执行路径，cwd 必须等于会话真实目录，网络和后代派生仍被禁止，私有环境白名单且不继承模型凭据；不通过 npx/npm 安装或包装启动。其他平台明确不可用。任务宿主继续禁止远程 HTTP 和外传，不因 MCP 确认而扩大权限；普通工作及全局只接受 HTTPS 或回环 HTTP。宿主事实逐次从服务端会话、命令及运行解析，不采用页面传入的权限。

结果只交付有界文本及受支持的 structuredContent，已知账号秘密在私有边界隐藏；非文本内容和截断明确说明。公开运行事件只发状态与摘要，MCP 账本保留去除已知秘密的文本以便对账。第三方结果是用户数据，不提升为指令。原生进程及实际调用复用任务额度；HTTP 关闭先等本地请求收敛，再终结会话，abort 返回不当作停止证明。正常普通会话结束只释放本轮快照，连接保留到用户断开/归档/应用关闭；任务、取消和失败会关闭所属连接。归入项目须先断开外接连接，避免旧连接继续使用原目录。

未知及重启：未发出工具调用的 prepared 取消，在途 running/cancel-requested 变为 unknown，旧 pending 许可失效，原成功事实不覆盖。stdio 在服务异常退出且缺少真实退出证明时保留任务原生租约，不能仅按 owner 退出自动解除；需沿原任务恢复流程核对残留进程与副作用。

验证边界：已覆盖真实公共工具声明、Pi 工具桥调用、Fake harness 调用、生产 Fake 应用装配及注入的协议流。当前执行环境禁止派生与网络，未启动实际 OS MCP 子进程、真实 HTTP 服务、真实模型或浏览器；这些不能由夹具通过推定为兼容性验证完成。

## 分类与调用许可

工具注解不授予可信等级。用户在实际确认入口登记效果，绑定配置、账号、目录及工具定义版本，支持撤销。多份仍适用的分类取效果并集，远程 HTTP 总会附加数据传输效果。分类是本地规则输入，无法检查第三方服务内部实现；不能宣称外部工具已被证明只读。

每次工具调用都要求独立 MCP 许可，包括已分类的读取。请求固定原宿主/运行身份、精确参数、服务来源、命令/地址、账号和版本。Inbox 使用独立 `mcp` 类型与同一个业务决定对象；只支持本次允许或拒绝，模型的 respond 通道拒绝处理 MCP 许可。许可和分类撤销不表示在途远端操作已停止。

确认及执行前均核对身份、目录、参数和宿主策略。目录变化、账号撤销、规则变化、过期及参数变更使旧请求不可用。启动恢复使上一进程 pending 请求失效，不重放旧决定。参数按有界 JSON Schema 子集核对；外部 $ref、正则、未实现约束及超限输入均拒绝，不能通过忽略约束继续执行。当前子集支持 object/properties/required/additionalProperties、数组、基础类型、枚举/常量、简单边界及 anyOf/oneOf。

全局 Multivac 在服务端拒绝第三方本地写和外部副作用；只读分类仍不能扩大目录、网络或数据外传权限。管理提议与实际工具调用分别确认，Git 发布和目录授权的业务流程保持独立。

## 账号与认证

MCP 使用实例数据根下独立的 `mcp-credentials.json`，复用 Pi 原生凭据存储与锁；键名包含实例身份与随机/命令派生的不透明引用，不与模型认证共用记录。秘密作为私有 JSON 胶囊保存，不调用模型认证解析器，不解析环境命令。账号公开对象、SQLite、事件与命令指纹不保存密钥、授权码、PKCE verifier、令牌或其摘要。

静态账号支持远程 Bearer，或 stdio 中显式列出的私有环境变量；禁止覆盖 PATH、HOME、NODE_OPTIONS 等运行环境。保存前先持久化无秘密意图，结果丢失只按原引用核对，不重新写入调用方再次提供的秘密。撤销先更新账号版本，使旧连接立即不可用，再清理私有值；旧撤销命令重放不能清理新账号版本的凭据。这里是本机撤销，不承诺远程提供方已吊销令牌。

OAuth 支持预先登记的公共客户端、授权码与 PKCE S256、固定本机回环回调、state/可选 iss/回调来源/时限核对，以及显式刷新和取消。认证端点必须为用户配置的同源 HTTPS 地址，网络策略逐地址核对；请求带精确服务 resource，不跟随重定向。交换与刷新先在私有锁内保存 exchanging/refreshing 意图，再发请求；未知结果不重发旧授权码或刷新令牌，须重新登录。刷新成功增加账号 revision，旧连接不静默采用新身份，须重新验证。过期状态只读呈现。

尚不支持自动授权服务器/受保护资源元数据发现、动态客户端注册、客户端密钥认证、设备码、跨域认证端点或非标准认证。登录 URL 只给本机账号交互页面，不向模型工具返回；实际授权由用户在提供方完成。受控提供方夹具验证的是 HTTP 编码和认证状态机，不表示已向外部提供方登录。

## 本地管理与原型对照

能力页在原 Skill 宿主中增加“服务与工具 / Skill”切换，两侧草稿独立保留，只有当前页签挂载页头操作。服务列表展示真实登记状态；详情分别展示公开配置、账号、连接、目录、服务声明、用户分类及调用结果，不把登记解释为授权。

配置仅接受显式粘贴或用户选择的 JSON 文件。预览只解析数据，不扫描其他应用目录、不读服务内容、不启动命令或登录。支持标准 mcpServers 及本产品公开传输配置；私有 env 值、请求头、URL 认证或查询参数，以及可识别的秘密启动参数被拒绝。env 只允许空占位，私有值在独立账号入口提交。来源和公开启动参数由用户核对，不能凭字符串扫描承诺识别所有秘密。预览有效期与修改目标版本固定；用户逐个确认后登记为停用服务，连接必须再次核对账号、会话、项目、宿主、命令/地址及实际目录。版本冲突保留草稿，展示最新配置，用户核对后才能采用新版本重做预览。

管理 HTTP 入口只装配给本地用户，远程访问仍默认拒绝。密码输入不回显旧值、不存入浏览器持久草稿，提交完成或响应未知后清除私有输入；未知时先查看账号状态或原命令记录，不自动重发秘密或连接。OAuth 链接仅在此账号页面短暂保留，由用户打开提供方页面，回环回调不向模型返回授权码或 state。服务回显已知凭据的目录会在落库前被拒绝，不通过修改 Schema 来隐藏泄漏。

项目详情提供排除与明确账号；智能体详情提供偏好与独立效果上限；会话授权窗口提供持续保存的临时停用。三个入口与实际执行共用 McpRules。归档会话可查看保留规则但不能修改。跨窗口变更或重连只刷新事实，不覆盖未保存输入；规则版本冲突要求用户核对并重新编辑。分类显示绑定版本，账号/目录变化后旧分类转为历史资料，不再显示为当前确认。

原型差异：对照 prototypes@d52053a 的 CapabilitySettings、项目权限和 SessionInfo。保留服务/Skill 页签、来源核对、目录与三个作用域入口；原型中的模拟连接和自动本机发现改为显式配置输入、真实状态与独立连接确认。使用独立效果集合代替线性外传等级。当前资源目录只展示元数据，不自动拉取资源或 prompts。移除后保留带“历史”标记的来源、连接及调用记录，停止未完成时仍可核对旧连接，不能从历史入口重新启用。

连接生命周期：同会话同服务只能有一个正在建立、活跃或待停止核对的连接。建连期间收到停止时，先取消并等待原尝试真正结束，再写本地停止证据；关闭并发共享同一操作。协议请求逐次核对账号、配置与有效规则；身份失效或规则拒绝时停止发送。全局 stdio 的工作目录额外拒绝写入。账号变化只清理旧版本连接，旧停用回执不能关闭之后的新连接。

连接记录新增可选 localStopConfirmedAt，旧记录兼容读取。重启后没有本地停止证明的记录保留原范围占用，不能因内存中没有连接而解除门禁；本实现不提供人工勾选替代停止证据的入口。HTTP 的 closed 只证明本地请求已经收敛；若账号撤销、DELETE 不支持或响应未知，保留 result-unknown，不向旧目标发送新凭据，也不宣称远程会话或副作用停止。

## 对话管理

全局工具集合实际注册 query_mcp_management 与 propose_mcp_management。查询只读已持久化的服务、公开账号状态、分页目录摘要、范围规则及原提议回执，不连接、不做网络探测、不读资源正文。工作及任务会话不获得管理提议工具。

接入/修改/批量导入、服务状态、范围规则和固定会话连接统一使用 mcp.manage 确认卡。服务端固定来源、公开命令/地址、服务及账号版本、旧/新范围和影响；用户确认前只保存预览和提议。私有凭据在管理页单独输入。卡片复用真实提议决定接口，模型及第三方文本没有批准端口。确认时事实变化或超过 15 分钟则失效；服务写事务和协议发送仍单独复核。

确认仅完成该项管理操作，登记、连接、分类、逐次许可与执行分别记账。批量导入失败保留已登记部分，不回滚后再重发。提议、业务命令和连接身份稳定；重复确认只读取原提议回执，服务重启中的执行转为结果未知，不自动重放。未知响应先按原提议及其对账命令查询持久事实，不能根据模型记忆宣布成功。

## 验证

选定验证覆盖事实与迁移、注入协议流、账号私有锁/认证状态机、Inbox、有效规则、Pi/Fake 公共工具桥、管理 HTTP 处理器、实际发送前的规则竞争、本地停止与静态分类视图。管理 HTTP 测试使用 IncomingMessage/Response 夹具，不表示实际套接字实测。检查包含 contracts/server/Web 类型检查；另覆盖对话真实注册、查询无探测、确认/取消、版本及目录变化失效、重复确认对账，以及真实确认卡静态渲染。

`artifacts/mcp/verify.mjs` 直接使用目录内 TypeScript API 和现有依赖，不派生进程或访问网络。`artifacts/mcp/ui-static.html` 由实际工具分类组件生成，只证明静态文案、版本失效呈现及文本转义；CSS 在 Node 验证加载器中为空模块，不执行浏览器布局。普通/窄栏布局、键盘焦点、跨窗口交互、Skill 浏览器回归、OAuth 跳转与真实传输仍未实测，需在人工验收中核对。
