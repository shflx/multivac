# MCP 接入契约

本文随实现更新。当前已实现数据契约、SQLite 持久化及公共协议客户端；认证、授权业务入口及页面尚未装配，不能用登记事实宣称 MCP 已可调用。

## 身份和状态

- 服务的 `serviceId` 稳定。`revision` 用于管理并发，`configVersion` 是不含凭据的传输配置版本。启停与连接、可发现能力及调用授权分别保存。
- 账号通过稳定 `accountId` 绑定一个服务。公开记录只包含不透明 `credentialRef`、认证类型和状态；私有存储负责凭据值，不能把值或其摘要写入业务记录。
- 工具身份由服务身份与原始工具名派生。完整工具定义（说明、Schema、注解）计算 `definitionVersion`。目录快照绑定服务配置与账号版本；工具、资源或模板变化产生新目录版本，不修改旧快照。
- 服务声明注解是资料。用户效果分类是独立事实，绑定配置、账号、目录及工具定义版本，并引用真实决定。存储接口不是确认入口，不能用模型文字创建用户决定。
- 项目规则包含排除与账号引用，智能体规则包含偏好及效果上限，会话规则包含临时停用。每个服务与作用域只允许一条规则。运行身份固定适用规则的 revision，执行时仍需重新核对。
- 调用固定宿主、会话、命令、工具调用、任务、运行及执行者身份。`sessionId + toolCallId` 唯一，不能换 `callId` 重放同一次执行。

## 持久化端口

`McpRepository` 提供有界读取、配置历史和稳定命令对账。变更只能通过 `commit` 提供的 `McpTransaction.put` 写入；expectedRevision=0 表示新建，其后必须恰好加一。事实、无秘密回执及变更事件在同一短事务内提交，失败一起回滚。异步回调不被接受；事务内禁止文件、网络、进程和模型调用。

MCP 使用独立的、按 JSON 键排序的 SHA-256 指纹规则，不改变其他模块的历史账本编码。同命令同参数返回原回执，同命令不同参数报冲突。回执只记录对象身份及 revision，不保存凭据或远程原始输出。

迁移追加到现有迁移序列，沿用既有数据库升级前备份。目录、导入预览及资源快照不可修改；服务配置历史保留。账号版本变化不改写历史调用，也不阻止记录旧连接的真实关闭事实。

## 状态迁移

调用状态允许 `prepared → running → succeeded/failed/unknown`。取消先记录 `cancel-requested`；只有停止证据才能记录 `cancelled`。未知结果只能由核对转成已知终态，不能重置为 running 自动重放。真实业务执行器仍须负责停止证明和核对依据，单凭存储状态迁移不构成证明。

授权请求的 pending 可以终结为 allowed、denied、expired、cancelled 或 invalidated，已终结决定不可改写。许可、执行和执行结果分别记录。连接每次创建新的连接身份，断线后重新连接不得复用旧身份伪装同一连接。

## 协议与兼容范围

公共客户端实现 JSON-RPC 初始化、能力协商、tools/resources/templates 分页目录及变更失效，协议版本限定为 2025-06-18、2025-03-26，以及仅用于 stdio 的 2024-11-05。无已安装 MCP SDK（lockfile 仅有 Pi 的可选 peer 声明），本实现未新增依赖；本轮未联网获取协议资料，不宣称通过官方 SDK 一致性测试。

stdio 使用 UTF-8 按行消息，通过宿主核对后的 `McpStdioChannel` 传输；客户端不能直接 spawn。Streamable HTTP 支持 POST 的 application/json 与 text/event-stream 响应、会话头、协议头及 DELETE 关闭；不重定向、不重试。独立 GET 事件流和事件游标恢复尚不支持，因此调用前须显式 refresh 目录，不能依赖空闲时收到变更通知。旧 HTTP+SSE 不支持，在创建传输前明确报错，不自动回退。

服务端采样、elicitation、roots 请求及 prompts 自动执行均不启用；除 ping 外的服务端请求返回方法未启用。限制单次请求/响应及整个目录为 2 MB，最多 1000 项、100 个分页游标，重复游标拒绝。默认 RPC 超时 15 秒，取消只发送通知并停止本地等待，不能宣称远端副作用已停止。

`McpConnections` 按服务、账号和会话保存真实连接事实，异步阶段后核对配置/账号版本；目录变更立即使缓存不可用，refresh 成功后保留新快照。重连显式创建新连接。关闭失败保留活跃记录，不提供停止证明。生产宿主的进程/网络策略和私有凭据通过 `McpWireFactory` 装配；该端口必须只构造传输，实际启动由 wire.start 完成，不允许在工厂返回前启动未受跟踪的进程。

传输配置只存公开启动参数、cwd、环境变量名或远程地址。远程 URL 不接受内嵌用户名、密码、查询参数或片段，认证由账号端口提供。配置校验本身不授权目录、网络或进程；必须在启动与调用时分别经过宿主策略。用户不得把凭据写入公开参数，导入入口还需执行秘密字段检查。

## 账号与认证

MCP 使用实例数据根下独立的 `mcp-credentials.json`，复用 Pi 原生凭据存储与锁；键名包含实例身份与随机/命令派生的不透明引用，不与模型认证共用记录。秘密作为私有 JSON 胶囊保存，不调用模型认证解析器，不解析环境命令。账号公开对象、SQLite、事件与命令指纹不保存密钥、授权码、PKCE verifier、令牌或其摘要。

静态账号支持远程 Bearer，或 stdio 中显式列出的私有环境变量；禁止覆盖 PATH、HOME、NODE_OPTIONS 等运行环境。保存前先持久化无秘密意图，结果丢失只按原引用核对，不重新写入调用方再次提供的秘密。撤销先更新账号版本，使旧连接立即不可用，再清理私有值；旧撤销命令重放不能清理新账号版本的凭据。这里是本机撤销，不承诺远程提供方已吊销令牌。

OAuth 支持预先登记的公共客户端、授权码与 PKCE S256、固定本机回环回调、state/可选 iss/回调来源/时限核对，以及显式刷新和取消。认证端点必须为用户配置的同源 HTTPS 地址，网络策略逐地址核对；请求带精确服务 resource，不跟随重定向。交换与刷新先在私有锁内保存 exchanging/refreshing 意图，再发请求；未知结果不重发旧授权码或刷新令牌，须重新登录。刷新成功增加账号 revision，旧连接不静默采用新身份，须重新验证。过期状态只读呈现。

尚不支持自动授权服务器/受保护资源元数据发现、动态客户端注册、客户端密钥认证、设备码、跨域认证端点或非标准认证。登录 URL 只给本机账号交互页面，不向模型工具返回；实际授权由用户在提供方完成。受控提供方夹具验证的是 HTTP 编码和认证状态机，不表示已向外部提供方登录。
