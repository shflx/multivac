## 真实执行证据

- `managed-processes.test.ts` 在 Seatbelt 内启动真实 Node HTTP 服务，核对可访问的回环端口；目录外读写、外部网络、其他本机监听端口、密钥环境与 detached 后代均不能越过边界。停止后连接失败，私有退出凭据存在。
- 长命令到达时间预算后退出。忽略 SIGTERM 的进程在服务管道断开后以 SIGKILL 收敛，凭据记录真实 signal。缺少匹配凭据或模拟 PID 复用时保持恢复核对，不按旧 PID 操作。
- 正常关闭清理独立进程。重复启动只创建一个进程；停止前版本变化拒绝执行，用户取消不停止，同命令重复提交返回原受理回执。
- `task-execution.test.ts` 经真实内部工具注册调用受控启动，随后暂停任务，核对依赖进程已退出。依赖退出证明不足时保留 Run 租约；迟到派发事件不能改回运行中。
- `runs.spec.ts` 的模型适配器为 fake，但进程、SQLite、HTTP、事件流和停止均为真实实现。独立进程在任务本轮结束后继续存在，对话查询与用户确认卡共用事实；模拟停止已执行而响应丢失，重试沿用原命令 ID。

## 实际限制

- 仅 macOS 验证；仅执行任务目录内直接 Node 脚本。禁止 fork 和外连，不支持 npm/Vite 子进程工具链或任意 shell，不引入容器。
- 单进程最多五分钟、1 MiB 输出，启动时进一步按剩余任务预算收窄；每任务四个、全局十六个未确认退出进程。没有进程内存硬配额。
- 日志仅展示最近 64 KiB 内完整行，常见敏感模式会遮蔽，但不保证识别任意业务秘密。
- 如果监护器与服务同时异常退出且没有可信退出凭据，保留资源占用与恢复核对；不自动杀旧 PID、释放租约或重启。
- 真实模型端到端尚未验证。Pi 集成测试使用本地响应夹具，不等于远端模型通过。

已有版本 25 的数据库升级测试验证新增表作为末尾迁移 26 添加，保持历史迁移顺序。基线缺失的交互与执行 HTML 已补充为本功能的设计说明，不声称重建了其他模块的历史设计。
