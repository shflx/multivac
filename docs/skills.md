# Skill 支持

设置 · 能力中输入本机标准 Skill 包目录，检查正文、文件变化、依赖与范围后确认导入。名称遵循 [Agent Skills 标准](https://agentskills.io/specification)，显示名称可用中文。包必须包含 SKILL.md；不会扫描用户或项目的默认目录，也不预置示例。

## 生命周期与范围

导入先保存受控快照和预览，确认时重新读取来源、核对内容哈希与旧 revision，再事务提交登记和命令回执。重复命令不重复登记，同范围同名或同来源冲突要求选择现有项更新。更新新增版本；停用和移除阻止后续发现/加载，不删除源文件或历史快照，也不能撤回已进入历史的正文。

全局 Skill 在各项目可发现，项目 Skill 只在所属项目可发现。项目隐藏与会话关闭是相关性偏好，不改变工具权限。依赖按包声明和用户补充分别保存；未声明仍显示未知，MCP 或宿主工具不存在时明确不可用。依赖判断不能代替实际文件授权或执行器限制。

## 调用与恢复

输入区键入 `/` 搜索，方向键与 Enter 选择，Esc 关闭。选择只更新草稿；界面标签背后的稳定 ID 和版本随原有草稿同步、命令指纹与历史保存。发送前复核范围和状态。选择后包更新仍使用选中版本，停用则拒绝发送，不静默换包。原始 `/Skill` 名称文本不算成功调用。

每轮 Pi 只收到最多 100 项、约 24K 字符的目录数据，不预读附件或未选正文。`skill_load` 才读取固定正文；`skill_resource` 按相对路径使用附件。原生 Skill 命令展开与默认目录扫描关闭。书伴不注入这些工具，只能显式使用已声明或由用户补充无工具依赖的正文，不能借包获得文件、命令或资源工具。

任务的 `skill` 引用随创建参数和记录保存，确认预览、创建及运行前核对可用性；创建不自动启动。模型仍需在交接时保留结构化引用，不能把名称写进任务目标当成已加载。

## 资料、模板与脚本

- `read`：UTF-8 资料最多 64 KiB，二进制请复制到工作目录后使用。
- `copy`：模板复制到工作目录内的新相对路径，拒绝覆盖已有文件，不修改快照。
- `run`：仅支持 macOS 原生隔离中的 `scripts/*.js` / `*.cjs` 单文件 Node.js 脚本，通过 stdin 执行；不支持包内模块相对 import、Python、任意 shell 环境或依赖安装。输入脚本最多 64 KiB，输出最多 64 KiB，30 秒上限。

脚本沿用现有 sandbox-exec 规则，禁止网络与派生进程，不继承模型密钥；可读系统运行库及当前工作目录，产物限工作目录。后台任务复用同一执行器和租约预算。取消后等待真实进程退出；执行前持久化意图，重复调用返回原结果，重启后未知结果拒绝自动重放。其他平台明确拒绝脚本执行。

## 对话草案与迁移

Multivac 的 `propose_skill` 只在用户明确要求时生成完整文本包及附件草案。确认卡展示正文、附件、变更文件、范围与诊断。取消不登记，确认时核对旧版本，登记成功后可使用；模型拿不到确认执行器。修改必须提供完整的保留文件集合，未提供的文件会在新版本移除。

Claude Code / Codex 来源入口只检查用户明确指定父目录的直接子目录，最多 100 个条目；不读取宿主认证、MCP 或插件配置。实际兼容范围是标准 SKILL.md 包，解析器复用安装的 Pi 0.85.1；宿主扩展字段仅保留并诊断，不宣称兼容所有宿主版本。导出 ZIP 仅包含原始包文件，不加入本机来源、登记元数据或使用记录；导出内容仍需由用户确认适合分享。

## 限额与已知边界

单包最多 256 文件、512 条目、8 层目录、8 MiB，总体单文件 2 MiB，SKILL.md 64 KiB。拒绝隐藏文件、非法路径、符号链接、硬链接和特殊文件；用户须给出真实规范路径，macOS 的 `/tmp` 等别名需要转换为真实路径。文件描述符和真实父路径复核缩小竞态窗口，不能宣称跨平台阻止所有恶意目录替换竞态。此实现不把普通会话原有 bash 当成安全沙箱。

快照先原子落盘再提交数据库，失败最多留下未引用的快照，不会发布半包。取消预览及孤立快照暂不自动回收。目录和使用记录来自服务端事实，变更经既有全局事件流刷新；断线重连重新读取。最近使用最多展示 100 条，时间指服务端读取时间，资源读取不代表脚本成功。脚本和工具结果在会话运行轨迹中核对。

## 验证

`skill-*.test.ts` 与 `skills-real-pi.test.ts` 覆盖包、生命周期、范围、固定版本、提议及资源。真实 Pi SDK 集成使用本地脚本模型验证摘要加载、工具读取、停用与公开轨迹；这不是外部真实模型的自动匹配质量证明。当前开发环境未配置模型与凭据，未进行真实外部模型验收。

`native-task-tools.test.ts` 和 `skill-resources.test.ts` 在 macOS 实际执行脚本，验证文件产物、复制、越界、网络、密钥环境、派生进程、取消与租约。`tests/e2e/skills.spec.ts` 使用真实应用存储验证导入、预览取消、键盘确认、停用、指定来源、ZIP 下载、草稿恢复及提议确认；模型端为测试替身。
